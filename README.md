# VR Dice Rolling Game

## Description
A Virtual Reality Progressive Web Application (PWA) that simulates dice rolling using phone movement and orientation. Built with JavaScript and Three.js, the application provides an interactive 3D experience through mobile device sensors.

Live Demo: [https://www.ardicegame.me](https://www.ardicegame.me)

## Installation
```bash
git clone https://github.com/azisauce/XR_Project.git
cd XR_Project
npm install
```

### Prerequisites
- Node.js v20+
- HTTPS-enabled server (for XR features)
- Modern mobile browser with device orientation API support

## Usage
This application requires HTTPS protocol to access XR features. To run the application:

1. Deploy the application on an HTTPS-enabled server (WildFly server recommended)
2. Access the application through a mobile device
3. Grant necessary permissions for device orientation and motion
4. Hold your phone and start rolling the dice!

## Features
- Interactive 3D dice that responds to real-world phone movement
- Realistic dice rolling physics triggered by phone shaking
- 360-degree view of the dice through phone orientation
- Progressive Web App capabilities for improved mobile experience
- Responsive design that works across different mobile devices

## Technical Requirements
- HTTPS protocol enabled server
- Mobile device with:
  - Accelerometer
  - Gyroscope
  - Modern web browser support
